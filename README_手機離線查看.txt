東京自由行 10 天行程與預算 - 手機離線查看方式

資料夾內容
- index.html：手機友善的離線網頁版。樣式都在檔案內，不需要網路。
- 東京自由行10天行程與預算.pdf：建議手機主要看這份，最穩。

iPhone / iPad
1. 打開 OneDrive App，找到「日本10天行程_離線文件」資料夾。
2. 點 PDF 旁邊的 ...，選「可離線使用」或「Make Available Offline」。
3. 也可以把 PDF 用分享功能存到「檔案」App 的「我的 iPhone」。
4. 沒網路時，從 OneDrive 的離線檔案或「檔案」App 打開 PDF。
5. HTML 若要開，點 index.html，若 OneDrive 預覽不順，選分享到 Safari / Chrome。

Android
1. 打開 OneDrive App，找到「日本10天行程_離線文件」資料夾。
2. 點 PDF 旁邊的 ...，選「保持離線」或「Make Available Offline」。
3. 也可以下載到手機的 Downloads 資料夾。
4. 沒網路時，用 OneDrive 離線檔案、Google Files 或任何 PDF 閱讀器開啟。
5. HTML 若要開，點 index.html，選 Chrome / Samsung Internet / Edge。

出發前務必確認
- 飛航模式開啟後，也能打開 PDF。
- VJW QR code、機票、住宿、保險、迪士尼、富士山票券都已截圖。
- Google Maps 已下載東京離線地圖。
